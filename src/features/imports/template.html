    Your circles

    Each circle is its own private atlas. Nothing crosses between them.

    How people join

    New members enter with a visible name and the circle’s shared code. Share the code only in person or in your own chat. A name is not proof of who is using it: anyone with the code can enter under any name.

    Removing someone closes the atlas for them at once and withdraws what they added. Copies other members imported themselves stay.

    Imports are shared with the whole circle immediately. Every member sees each item the moment it is processed. Check an export before you add it. Each photo, its original, filename, dates, locations and the messages around it become visible to every member the moment it is processed, before the import finishes. There is no private stage, so check an export before adding it. You can withdraw your contribution afterwards.

    Start the atlas with your first export

    Pick where your photos and chats live. Each source shows how to export from that app.

    Add a chapter

    Up to 128 MiB compressed / 512 MiB expanded. JPEG and PNG photos up to 25 MiB and 24 megapixels. Video, HEIC, animation and other formats receive an unsupported outcome. Remote attachments are never downloaded.

    If transfer stops, select the same file and account label to resume. Inspect the inventory before starting group ingestion.
