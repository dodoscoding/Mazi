# Event notebook direction

Mode: Operate with a reading emphasis. This is an extension of the existing memory detail, not a replacement visual identity or a new page composition. No concept tournament or generated comp is needed for this local addition.

## Confirmed task

The member clicks an event title and reaches imported chat excerpts plus notes written by the circle, within the event page. The owner confirmed this placement through the structured question. Text should be visible promptly on arrival. Ordinary photo navigation retains the photo viewer.

## Established world

Use the implemented Luminous night palette, Instrument Serif display typography, Geist body text, existing rounded controls, focus rings, and motion tokens. Photos remain the real memory artifacts. Conversation evidence uses the existing cool accent; recollections carry the warm memory accent. Keep sender and date context factual. Sample material stays visibly synthetic.

## First viewport on title arrival

The notebook heading and readable text are in view after a title click. Members can recognize imported conversation and authored recollections as separate content. A concise invitation to add a recollection and a clear saved-note editor make contribution discoverable. The layout stacks naturally on a phone and permits document scrolling rather than a nested reading pane.

## Signature interaction

The title opens its own event notebook directly. A restrained reveal carries the transition from discovery to reading. Opening the inline editor preserves reading context; saving replaces the saved note while keeping any newer draft. Reduced motion uses a short fade or immediate change. Clear labels, comfortable line length, and conversational spacing provide the delight.

## Quality bar

- All existing event notes remain visible, even when a member wrote in several historical stories.
- Imported excerpts and member recollections remain distinguishable.
- The author can save, edit, remove, recover a failed save, and refresh a conflict in place.
- Loading, empty, error, unavailable, pending, hover, focus, and disabled states are explicit.
- Desktop and phone, the shipped night theme, keyboard and reduced motion remain usable with no horizontal overflow.
- Original photos, factual copy, source access, and unrelated UI keep their existing behavior.
