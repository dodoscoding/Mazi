Choose candidate A, retaining Python behavior and integrating scoped feature modules into React. Accept the design with the integration conditions below. This is an independent same-family source review of `design-brief.md`, `backend-map.md` and `frontend-map.md`; no runtime verification or cross-family validation is claimed.

Candidate B adds a behavioral migration without resolving a user requirement that A cannot meet. Graft its shared typed client boundary into A. The frontend map's recommendation to retain the Phase 7 handler chain must mean retained behavior only. Follow the backend map's single dispatcher and actual renamed implementations. Package placement must agree with the promised `python -m mazi` command from the repository root.

## Significant integration risks and required proof

1. **Private lifecycle ownership.** [memories.js](../../../src/features/memories/mount.js) installs document/window listeners and a `DOMContentLoaded` initializer; [advanced.js](../../../src/features/memories/mount.js) depends on globals and creates asynchronous media URLs. [imports.js](../../../src/features/imports/mount.js) starts an unowned polling interval. Wrapping these scripts without changing ownership leaks work between screens. Each mount needs root-scoped element lookup, explicit initialization, abort signals, a disposed/generation guard on every asynchronous continuation, timer/listener removal and media disposal. React StrictMode mount/dispose/remount must remain safe. Shared session/group invalidation must clear Atlas, drafts and feature media on logout, group change, denial and backgrounding. Test delayed responses and mutation/export completion during those transitions. Aborting a request does not undo a server mutation.
2. **Real domain consolidation.** [server.py](../../../mazi/memories/server.py) inherits the preceding numbered handler and injects links into HTML response bytes. Remove that runtime chain and static-screen serving; preserve its authorized routes in a domain dispatcher. Mounted templates must contain feature fragments only, with no document/head/body, scripts, duplicate shell or full-page navigation. Retire numbered imports, launcher commands and hardcoded helper/model paths. Reference fixtures and historical documents may retain phase names.
3. **Live Atlas authorization.** [MemoryStore._approved](../../../mazi/memories/memories.py) suppresses an entire event when any original asset becomes inaccessible. The proposed `/api/atlas?group` projection must reuse that rule in a consistent read transaction, use authorized origins and selected renditions, and handle undated/cross-year events without borrowing the annual recap's stricter date filter. Keep event IDs separate from asset/story IDs. Clear stale detail and GPU textures on invalidation. Prove a reviewed import reaches Atlas and that hiding or withdrawing one original suppresses its title, detail and story. An empty personal archive must not silently become the demo archive.
4. **Storage and worker compatibility.** [Store](../../../mazi/identity/core.py) opens `mazi.sqlite3`; [ImportStore](../../../mazi/imports/engine.py) enables WAL and stores archive files beneath the selected root. Keep `.mazi-imports` and its complete schema/file layout; do not merge `.mazi-pilot` or seed on ordinary startup. Reopen a populated synthetic root with the renamed store and compare IDs, bytes, grants, story revisions and capsules. Start exactly one [source worker](../../../mazi/sources/server.py) with its own connection and bounded shutdown. An independent copy or supported SQLite backup must include committed WAL data.
5. **One-origin runtime proof.** [identity server](../../../mazi/identity/server.py) supplies no-store, cookie and CSP headers; [memory server](../../../mazi/memories/server.py) compares Origin with Host. Vite proxy Host rewriting can make valid mutations fail. Test real UI login/import/story mutations through the documented development URL and built server, rather than weakening Origin checks. Verify Fiber/React styles and development resources under the actual CSP. Static serving must never expose the data directory. Preserve `/api/*` denial and binary responses instead of sending SPA HTML for missing API routes.

## Acceptance evidence

Run existing backend unit/HTTP contracts through renamed imports and integrated desktop/phone browser workflows covering every action in the frontend inventory. Add cross-screen stale-request, access-loss, backgrounding and repeated-mount checks. Preserve the Phase 7 server-time capsule, contribution ownership, revision conflict, per-frame/video authorization and explicit-download tests. Validate populated-root restart, launcher startup/failure/shutdown, and built-mode serving. Existing phase browser tests against standalone pages and a passing TypeScript build alone cannot establish consolidation.

Model the Domain shaped the decision to move owning implementations and centralize shared session/group state. Prove It Works shaped the requirement for same-origin integrated workflows and populated-root compatibility evidence. The comments workflow is outside this design-only assignment; no application edits were made.
