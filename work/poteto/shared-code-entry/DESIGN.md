# Shared-code entry visual plan

The new screens extend the Atlas identity documented in the root DESIGN.md. They do not redesign the existing archive pages.

## Tokens

Use the existing CSS variables: midnight ground #091b29, blue surface #102737, ivory ink #f3e5cf, mist text #adbac0, copper accent #e5a16c, and action fill #ae572d. Libre Caslon Text carries the title and short introduction. Source Sans 3 carries labels, fields, errors, and utility links.

## Layout

Login is a calm, narrow form with the Mazi wordmark, a brief private-circle greeting, visible name, shared code, and one Enter Mazi button. Do not show navigation, real photographs, sample links, or explanatory onboarding before entry. On desktop, use deliberate negative space around the form. On phones, use the existing 24px page gutters and full-width fields.

Welcome is one short page after entry. It introduces shared memories, the Atlas, and the existing import path. Use a simple cartographic motif drawn from the current interface rather than adding photographs before there are actual memories. One Open the Atlas action marks the introduction complete. About reuses the same explanation without resetting completion.

## Review against the request

Retain the established palette and fonts because the user explicitly requested keeping the existing pages. Avoid a separate marketing theme, promotional metrics, decorative card grids, or a multi-step tour. Focus the visual distinction on the Atlas motif and typography. Use visible labels and focus rings, readable errors, touch-sized controls, reduced-motion behavior, and no horizontal overflow at narrow widths.
