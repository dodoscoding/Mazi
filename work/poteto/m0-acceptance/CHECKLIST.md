## Definition of done

M0 closes only when accepted scope/privacy/limits and browser targets are recorded, every currently promised importer has a fixture and declared format, and a repeatable real database and private-object experiment demonstrates automatic per-item sharing and denial to outsiders and removed members. The owner reports positive feedback from 2-3 friends. Runtime experiments use synthetic fixtures. M1 production acceptance remains separate.

## Throughput checkpoint

The critical path is the real database/storage denied-access experiment. One writer owns experiment code; one owns canonical acceptance docs after product answers arrive. Design candidates write separate files. Review starts after both units pass. Local Supabase avoids paid provisioning and protects real archives. The Atlas visual design stays as accepted. No UI screenshot update is needed unless UI code changes.

## Skips and boundaries

- Production provisioning, deployment and merge are outside this request.
- Native experiments are deferred under D07 and D13.
- Cross-family review is unavailable in the supported agent pool; use independent agents from one family and disclose it.
- Cursor transcript files are not inspected. Evidence comes from commands, committed artifacts and this task's messages.
- Origin cannot resolve dodoscoding/Mazi; use GitHub CLI for all PR operations.

## External handoff

Publish and attach the ready PR as the final action. The attached PR artifact and final chat reply report the actual GitHub outcome. No merge, deployment or ongoing PR monitor is requested.
