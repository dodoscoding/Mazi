# Atlas prototype execution plan

Approved scope: team chose The Atlas of Us and requested the stack decision and interactive Home → memory → photos/context prototype on 3 October 2026. The chosen image is the composition reference. This implementation proceeds from that explicit build request without reopening the direction tournament.

1. Record D16 (prototype scope/stack) and the Atlas surface contract. Preserve historical source documents.
2. Generate synthetic, local photographs; author a procedural curved date chart. Establish Vite/React/TypeScript, Fiber/Three, CSS and Playwright.
3. Expose journey/history/recovery contracts as failing browser tests before implementing the flow.
4. Implement one shared selection, accessible HTML navigation, 3D selection, local photo gallery/context, URL history, responsive and reduced-motion paths.
5. Build/typecheck; test desktop/mobile, interruption, failed photos, renderer loss, history, keyboard. Capture and inspect desktop/mobile. Independent finish review; record evidence and design tokens.

No accounts, uploads, real personal data, hosting provisioning, telemetry, paid assets or backend are part of this experiment. Demo Timeline/Search may browse the same fixtures; imports/settings are explicitly unavailable.
